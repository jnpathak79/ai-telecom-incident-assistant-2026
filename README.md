# AI Telecom Incident Management Assistant

AI-powered telecom operations assistant designed to automate incident triage, RCA analysis, escalation intelligence, and workflow automation using GenAI, Python, and n8n.

## Features
- AI Incident Summarization
- RCA Recommendations
- Escalation Intelligence
- Workflow Automation
- Telecom Operations Insights

## Tech Stack
- OpenAI
- Python
- Streamlit
- n8n
- Power BI
